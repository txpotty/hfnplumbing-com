    Batch-Feed Disposal Installation in Durham, NC

    Batch-feed units only run with the lid in place, and the lid holds a magnet that closes a switch inside the unit.     High-Capacity Disposal Installation in Durham, NC

    A 1 HP disposal earns its keep in a busy kitchen, like an InSinkErator Evolution or a Waste King Legend model.     Disposal Installation on an Existing Sink in Durham

    For a common 1/2 or 3/4 HP disposal, we remove the old unit if there is one and install the new one on the existing sink. We connect it to the drain, set the P-trap and wire it, then check the clearance under the sink, which can be tight in older Durham homes with shallow cabinets or a water filter mounted on the back wall. Cramped cabinets take some planning. A compact unit can solve it.

    Dishwasher Connection With Disposal Installation in Durham

    Every new disposal has a plug sealing the dishwasher inlet. We knock it out with a screwdriver and hammer, fish the plug out of the chamber and connect the hose with a new clamp. A plug left in backs up the dishwasher. An air gap or high loop goes in too, which keeps sink water from running back into the dishwasher.

    Disposal Installation for Double Sinks in Durham, NC

    Double bowl sinks put the disposal on one side and a continuous waste or end outlet tee on the other. The layout keeps both bowls draining and stops the disposal from pushing water into the second bowl, a problem when the tee is too close to the discharge. Heavy-wall fittings last longer.

    Disposal Upgrades in Durham, NC

    Upgrading from an old 1/3 HP unit to something quieter is a common request. We disconnect and remove the old disposal, check the trap and drain arm for corrosion, and install the new unit with a new mount, so the upgrade does not inherit the old unit's worn parts. Corroded drain arms get swapped. Galvanized arms rust from the inside.

    Commercial Disposal Installation in Durham

    Commercial disposals run 1 to 5 horsepower and usually need a dedicated circuit, a control panel and a water solenoid. We set the unit on the mounting collar, run the drain to the grease trap where the local rules require it, and wire the controls so the water runs whenever the motor does. Local rules differ. The local rule gets confirmed before ordering.
