    Rough-In Plumbing for Urinals in Durham, NC

    Rough-in decides whether the finish goes smoothly. We set the carrier, run a 2 inch waste line to the outlet height on the spec sheet, stub the 3/4 inch supply where the flush valve will land, and tie the vent in before anyone hangs drywall. Inspectors see it open. Then the walls close.

    Drainage and Venting for Urinals in Durham, NC

    Urinal drains clog with scale, not paper. Urine leaves a hard mineral buildup inside the trap and the drain line, especially on waterless units and low-flow fixtures that send less water through, so we slope the line properly and add a cleanout where we can. A proper vent keeps odor out. We tie in within code distance.
