    From Carrier to Flush Valve in Concord, NC

    Flush Valve Urinal Installation in Concord, NC

    Flush valve urinals are the commercial standard. A flushometer from Sloan or Zurn delivers a measured volume from a 3/4 inch supply with no tank, and it recovers instantly for the next user, which matters in a stadium or school restroom. The volume matches the fixture rating. Wrong settings stain bowls.

    ADA Urinal Installation in Concord

    Accessible urinals start at the carrier. We set the carrier so the finished rim lands at 17 inches or lower, keep the clear floor space free of partitions and door swings, and mount the flush handle or sensor where a seated user can reach it. We measure the rim twice. Inspectors measure too.

    Urinal Rough-In for New Restrooms in Concord

    Tenant improvements need rough-in before the walls close. We lay out each urinal at 30 inches center to center and 15 inches from the side wall, set the carriers, and run waste, vent and supply so the finish crew can hang fixtures as soon as tile is done. We stay in touch with the GC daily. Rough inspection comes first.

    Flushometer Urinal Installation in Concord

    Manual flushometers are still the most common setup. Manual valves go on a 3/4 inch line with the control stop tuned and the vacuum breaker at the correct height. Handle side follows the layout. ADA units need the handle within reach.

    Urinal Brands We Install in Concord, NC

    Brand choice is mostly about parts support. American Standard, Kohler, Zurn and Sloan all make reliable urinals, and we steer customers toward models whose flush valves and cartridges are stocked at local supply houses so a repair never waits on shipping. Each of those brands is routine for us. Spec sheets come first.

    Urinal Installation Cost Factors in Concord, NC

    Carrier work is the biggest cost swing. Reusing a carrier and lines is cheap, while new carriers and pipe runs through finished walls cost more. Sensor valves add a few hundred. We itemize each piece.

    American Standard and Kohler Urinal Installation in Concord

    American Standard and Kohler make the china we install most. Washbrook and Bardon models come in several flush ratings, and the valve has to match the bowl. Matching is simple with the spec sheet. We order both together.

    Rough-In Plumbing for Urinals in Concord, NC

    Rough-in decides whether the finish goes smoothly. We set the carrier, run a 2 inch waste line to the outlet height on the spec sheet, stub the 3/4 inch supply where the flush valve will land, and tie the vent in before anyone hangs drywall. The rough gets inspected before cover. Then the walls close.
